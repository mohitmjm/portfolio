# Mohit Mohatkar Digital OS

A cinematic, futuristic portfolio for Mohit Mohatkar built with React, Vite, TypeScript, Tailwind CSS, Framer Motion, React Three Fiber, and Pyodide.

## Routes

- `/` — 3D scroll-controlled portfolio experience
- `/smart-hr-portal` — Smart HR Portal case study and module walkthrough
- `/compiler` — in-browser AI Python compiler

## Scripts

```bash
npm run dev
npm run lint
npm run test
npm run build
```

The Netlify configuration preserves SPA routing and cross-origin isolation headers required by the Pyodide compiler.
