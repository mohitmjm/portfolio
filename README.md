# Mohit Mohatkar - Personal Portfolio


**Live Demo:** [mohitmohatkar.in](https://mohitmohatkar.in)

Welcome to the repository for my personal developer portfolio! This project is a modern Single Page Application (SPA) showcasing my skills, projects, and professional journey. It was completely redesigned with a sleek **Electric Blue** glassmorphism aesthetic.

## 🚀 Technologies Used

- **React 18** + **Vite** (Fast, modern frontend tooling)
- **Framer Motion** (Smooth scroll reveals, page transitions, and micro-interactions)
- **Vanilla CSS** (Custom global design system, CSS variables, and glassmorphism styling)
- **React Hook Form** (Form state management)
- **React Icons** (SVG icons)

## 🎨 Design Highlights

- **Dynamic Hero Section:** Interactive mouse-reactive particle background and magnetic call-to-action buttons.
- **Glassmorphism UI:** Translucent frosted-glass panels, glowing borders, and deep shadows.
- **Electric Blue Theme:** Unified color palette using tailored `#3b82f6` primary and `#06b6d4` cyan accents on a dark navy backdrop.
- **Interactive Components:** 3D flip cards for skills, floating-label inputs, and custom cursor mapping.
